## 更新规则

1. 「依赖」中的卡合入 `main` 前，后续卡不得开工；例外必须写入 `DECISIONS.md`。
2. PR 创建后填入 PR 链接；开发机门禁通过后填结果 SHA；主代理合并后填合并 SHA。
3. 损坏、阻塞或返工必须写明具体条件；等待构建槽、CI 或依赖不算空闲。
4. 本表只覆盖阶段 S；阶段 N 在阶段 S 终验签收后再建表。
