## 0. 使用规则

1. 每个 issue 的「建议动作」和「建议标签」是内部执行提示，不要粘贴到 GitHub。
2. 「可粘贴草稿」才是拟公开发布文本；发布前再核对当时最新版本号。大部分修复首次包含于 **v0.20.16**，当前基线为 **v0.20.23**。

4. 参考数据必须写清边界：不冒充学校实时占用、实时库存、官方测绘或实时价格。
5. 阶段 S 只清账、补回归证据和预留接口；论坛 / 私信本轮不实现业务功能。

### #46 增加哈啰帮扫二维码功能，收取手续费

- 建议标签：`proposal`、`wontfix`。
- 依据：MASTER_PLAN §3.3。

```markdown
感谢提出想法，但这个方向不会做，本 issue 将按 wontfix 关闭。

原因有三点：

1. 帮他人使用自己的月卡扫码，大概率涉及共享单车平台账号和权益的转借，存在违反平台用户协议的风险；
2. 「抢单 + 报价 + 抽手续费」实质上会成为资金撮合和中介服务，需要支付、经营与纠纷处理能力，也会让应用承担交易纠纷责任；
3. 项目契约要求资金和使用边界真实、克制，核心校园工具不应把平台权益转借和收费撮合包装成功能。

因此不会实现代扫码、抢单或手续费抽成。建议需要单次骑行的用户直接使用平台官方单次付费或官方优惠活动。
```
